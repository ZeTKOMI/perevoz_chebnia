# 🪨 Учёт щебня GH

Веб-приложение (PWA) для учёта привезённого щебня: рейсы, автопарк, фотофиксация, инфографика и отчёты. Работает **полностью без интернета**, ставится на телефон как обычное приложение, данные хранятся на устройстве.

Разработано для маршрута **Чиньяворик → Объячево (запасник)**.

## ✨ Возможности

| Раздел | Что умеет |
|---|---|
| 📊 **Главная** | Инфографика по дням, фракциям и автомобилям; KPI за сегодня и за всё время; линия плана на день |
| 🚛 **Рейсы** | Журнал с фильтрами по датам, авто, фракции + поиск; автопересчёт **кг ↔ м³** по плотности (31,5–63 → 1,40 т/м³, редактируется) |
| 🚚 **Автопарк** | Карточки машин: номер, марка, грузоподъёмность, водитель, статус, фото, статистика по каждой машине |
| 📷 **Фото** | До 4 фото на рейс (кабина с номером + кузов с щебнем), автосжатие, просмотр в лайтбоксе |
| 📤 **Экспорт** | Отчёты в **Excel (.xls)** и **Word (.doc)**, скачивание фото и фотоотчёт одним файлом — всё с фильтрами по датам/авто/фракции/типу фото |
| 🔄 **Синхронизация** | Автоотправка каждого рейса в **Google Таблицы** (Apps Script) + резервные копии в JSON |
| ⚙️ **Настройки** | Тёмная/светлая тема, справочники фракций и маршрутов, план на день, бэкап/восстановление |

## 🚀 Быстрый старт

Никаких зависимостей и сборки — чистые HTML + CSS + JS.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/uchet-schebnya-gh.git
   ```
2. Откройте `index.html` в браузере — приложение уже работает.
3. Для полной функциональности (установка как приложение, офлайн-кэш) разместите файлы на любом хостинге с **HTTPS**.

### Публикация на GitHub Pages

1. В репозитории: **Settings → Pages → Source: main branch → Save**.
2. Через 1–2 минуты приложение доступно по адресу `https://ВАШ_ЛОГИН.github.io/uchet-schebnya-gh/`.
3. Откройте адрес на телефоне → «Установить приложение» (или через меню браузера «Добавить на главный экран»).

## 📱 Сборка APK для Android

### Способ 1: PWABuilder (рекомендуется)

1. Опубликуйте приложение на любом хостинге (см. GitHub Pages выше).
2. Откройте [pwabuilder.com](https://www.pwabuilder.com) → вставьте URL.
3. **Package for Stores → Android** → скачайте `.apk` / `.aab`, при необходимости подпишите и установите.

### Способ 2: AIDE прямо на телефоне

1. Установите **AIDE – Android IDE** из Google Play.
2. Создайте проект *Android App (Java)*, пакет `com.greenhouse.schet`.
3. В корне проекта создайте папку `assets` и положите в неё `index.html`.
4. Замените `MainActivity.java` на WebView-обёртку (код — в [вики проекта](../../wiki) или в обсуждении).
5. В `AndroidManifest.xml` добавьте разрешения `CAMERA`, `READ_MEDIA_IMAGES`, `READ_EXTERNAL_STORAGE` и `android:hardwareAccelerated="true"`.
6. Нажмите ▶ — APK собран и установлен.

## 🔄 Синхронизация с Google Таблицами

В приложении: **Настройки → Синхронизация с Google Таблицами** — там пошаговая инструкция и готовый код скрипта. Кратко:

1. Создайте таблицу на [sheets.new](https://sheets.new) → **Расширения → Apps Script**.
2. Вставьте скрипт `doPost(e)` (есть в настройках приложения), сохраните.
3. **Развернуть → Веб-приложение**, доступ «Все», скопируйте URL `…/exec`.
4. Вставьте URL в настройках приложения — каждый новый рейс будет автоматически появляться на листе «Рейсы».

> Фото в таблицу не передаются (тяжёлые) — они хранятся локально и выгружаются через «Экспорт → Фото».

## 💾 Данные и приватность

- Рейсы, автопарк, справочники — `localStorage`.
- Фото — `IndexedDB` (со сжатием до 1600 px / JPEG 0.78).
- Всё хранится **только на устройстве**, никуда не отправляется, кроме явно включённой синхронизации с вашей таблицей.
- В настройках есть резервная копия в файл `.json` и восстановление из неё.

## 🛠 Технологии

- Чистый **HTML / CSS / JavaScript** — без фреймворков, без CDN, без сборки.
- Графики — собственные **SVG** (работают офлайн).
- **PWA**: manifest + service worker (установка, офлайн).
- Хранилище: `localStorage` + `IndexedDB`.
